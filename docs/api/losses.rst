Funções de Perda (``ddsp_sonar.losses``)
=========================================

Funções de perda adaptadas para o domínio submarino.

No DDSP musical, a perda é calculada no domínio espectral (STFT multi-escala).
Para sonar passivo, as métricas relevantes são calculadas sobre
representações específicas do domínio: espectrograma LOFAR e envelope DEMON.
