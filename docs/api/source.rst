Módulo de Fonte (``ddsp_sonar.models.source``)
===============================================

Módulo responsável pela síntese das linhas espectrais da fonte radiante.
Equivalente submarino do ``HarmonicAudio`` do DDSP musical.

A fonte é caracterizada pela **frequência de lâmina de hélice** (*blade rate*)
e suas harmônicas — as linhas LOFAR que identificam a assinatura do navio.
